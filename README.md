# Hierarchical Clustering Dendrograms with Python and SciPy

Python script computing hierarchical clustering (linkage) and drawing dendrograms with SciPy, on Mariana Trench morphometry. Reusable data-analysis example.

## Scripts

- `dendrogram.py`

## Data

- `Tab-Morph.csv`

## Requirements

Python 3 with `matplotlib`, `numpy`, `pandas`, `scipy`.

```
pip install matplotlib numpy pandas scipy
```
